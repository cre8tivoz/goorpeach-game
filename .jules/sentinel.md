## 2026-11-22 - [SENTINEL] Harden /api/scores Body Limits, Same-Origin Enforcement, and Persistence Sanitisation
**Vulnerability:** `POST /api/scores` crashed with an unhandled `TypeError` (500) on `null` JSON payloads, buffered unbounded chunked bodies via `request.text()` before checking UTF-16 `.length` instead of UTF-8 byte length, matched `Content-Type` with `.includes('application/json')` (allowing parameter spoofing like `text/plain; x=application/json`), omitted same-origin `Origin`/`Sec-Fetch-Site` enforcement on `POST`, and leaked unhandled Worker exceptions on D1 outages. On the client, `Persistence.unlockLevel`, `Persistence.setSettings`, and `Scoreboard.submitLocal` could write or return unsanitised values.
**Learning:** Checking `Content-Length` alone does not protect Cloudflare Workers/Pages Functions from chunked transfer bodies, and `JSON.parse()` can return `null` or primitives that bypass TypeScript `as Partial<Record<...>>` assertions at runtime.
**Prevention:** Always stream request bodies with a hard byte accumulator and `TextDecoder('utf-8', { fatal: true, ignoreBOM: false })`, verify parsed JSON is a non-null plain object, match MIME type on the semicolon-split media type, enforce `Origin`/`Sec-Fetch-Site` checks on same-origin `POST` endpoints, catch D1 errors into structured `503` responses, and sanitise client persistence writes as well as reads.
